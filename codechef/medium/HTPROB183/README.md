## Problem

### Task - Build a Weekly Schedule

 **Goal:**  Create a detailed weekly schedule using `<table>`, `<tr>`, `<th>`, and `<td>` tags to organize a full week of classes.

 **Instructions** 

- Create a <table> element and add the border="1" attribute to make the table visible.
- Build your header row with <th> tags for the "Time" column and all five weekdays, from "Monday" through "Friday."
- Add at least three data rows for your different time slots.
- Inside each row, use <td> tags to fill in the class names for each day.

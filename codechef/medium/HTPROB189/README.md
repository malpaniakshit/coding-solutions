## Problem

### Task 2 - Build a Conference Schedule Table

 **Goal:**  Practice combining `colspan` to merge time slots and `rowspan` to represent sessions spanning multiple slots.

 **Instructions** 

- Create a <table> with a visible border.
- The first row should have headers for the days of the conference: A <th> for "Time" Then use <th colspan="3"> for "Conference Days".
- The second row should split the conference days into individual <th> headers: "Day 1", "Day 2", "Day 3".
- Add rows for the time slots: For example: "9:00 – 10:00", "10:00 – 11:00", "11:00 – 12:00".
- In Day 1, create a keynote session that spans two time slots using rowspan="2".
- In Day 2, create a "Workshop" that takes up two columns (Day 2 & Day 3) at the same time using colspan="2".
- Fill in the other cells with appropriate dummy session names like "Networking", "Panel Discussion", "Break", etc.
